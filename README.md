# cwi-kit

The one studio repository every CWI machine clones, including a client's server. Conventions and tooling, never data.

It defines the **room** (the operations folder every product, client, kit and the studio keeps), generates the router files an agent reads on entering any folder, keeps rooms committed and in sync between machines, enforces the no-loose-files rule, and rebuilds the whole tree on a fresh machine.

Python 3.10+, standard library only. Tests with `unittest`.

## Install

```bash
git clone https://github.com/aniket328/cwi-kit ~/Desktop/CWI/kits/cwi-kit   # or anywhere
~/Desktop/CWI/kits/cwi-kit/scripts/install.sh                                # symlinks ~/.local/bin/cwi
cwi --version
```

## Commands

| Command | Does |
|---|---|
| `cwi ws init <path> --name N --kind K --owner O [--mode repo\|embedded] [--remote URL]` | Create a room from templates (idempotent), the manifest, memory symlinks, the workspace router and hooks |
| `cwi ws meta [path]` | Regenerate `_meta.md`, `CLAUDE.md`, `AGENTS.md`, `.claude/settings.json` from the manifest |
| `cwi ws link [path]` | Symlink Claude Code memory directories into `<room>/memory/` |
| `cwi room check [path] [--json]` | Schema conformance; exit 1 on violations |
| `cwi sync [path\|--all] [--ops-only] [--no-push]` | Commit + pull + push the room; pull clean code repos; pin kits. Never commits code |
| `cwi doctor [path\|--all] [--json]` | No-loose-files rule, repositories without remotes, stale dirty or unpushed repos, room conformance |
| `cwi registry` | Rebuild `operation-room/REGISTRY.md` + `registry.json` |
| `cwi bootstrap [--root DIR] [--registry FILE] [--only NAME]` | Rebuild the tree from the registry; `--only` for a client server |
| `cwi hook start\|stop\|end` | What the Claude Code hooks call: inject state; commit; commit + push |

The schema itself: [`docs/ROOM-SCHEMA.md`](docs/ROOM-SCHEMA.md). Design record: `operation-room/docs/superpowers/specs/2026-09-05-cwi-kit-v0-design.md` in the studio's private repository.

## A workspace

```
<workspace>/                      plain folder
  _meta.md  CLAUDE.md  AGENTS.md  .claude/settings.json     generated by cwi ws meta
  ops/                            the room (repo mode): STATE MEMORY AGENDA manifest log/ runbooks/ memory/
  <code repos>/                   listed in ops/manifest.json; never auto-committed
  kits/<kit>/                     cloned at the pinned ref
  _scratch/                       disposable
```

## Hooks

`.claude/settings.json` (Claude Code) and `.codex/hooks.json` (Codex, with `hooks = true` in `.codex/config.toml`; run `/hooks` once in Codex to trust them) in a workspace get three hooks: `SessionStart` prints `STATE.md` and the agenda's Next list into context; `Stop` commits the room locally after every turn; `SessionEnd` commits and pushes. All silent, none ever fails a turn. A log of what they did is in `<workspace>/.cwi/sync.log`.
